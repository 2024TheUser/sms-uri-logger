# SMS URI Logger (en version)
A minimalist POSIX shell utility for intercepting and logging SMS URIs (`sms:` and `smsto:`) on Linux. Useful for capturing SMS URIs on a desktop system when no other handlers are available.
## Installation
```bash
sudo dpkg -i sms-uri-logger.deb
```
